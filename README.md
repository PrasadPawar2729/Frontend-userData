# 📜 User List with Search Filter

## 🚀 Challenge Overview
This React challenge involves building a **user list** that fetches data from an API, displays it in a styled format, and allows users to search by name. The application also handles loading and error states effectively.

## 📌 Features
✅ Fetch user data from [JSONPlaceholder API](https://jsonplaceholder.typicode.com/users)  
✅ Display user **name** and **email** in a list format  
✅ Implement **real-time search filtering** by name  
✅ Show **loading** state while fetching data  
✅ Handle **API errors** gracefully  
✅ Use **React functional components** with **hooks** (`useState`, `useEffect`)
